# dr-lerutla
The official website for the healthcare centre, Dr. Lerutla.

A static site with no build step: open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, cPanel).

```
index.html            single-page site
assets/css/styles.css brand tokens (green ring #1E8E3E, red cross #D7262E) and layout
assets/js/main.js     mobile menu, service filters, scroll reveal
assets/img/logo.svg   centre logo (green ring + red cross)
assets/img/favicon.svg
```

## Practices featured
- **Dr S.P. Lerutla**: free Voluntary Medical Male Circumcision (013 265 1097 / 076 587 6330)
- **Lebatle Renal Care**: dialysis and kidney care (083 960 8932, info@lebatlerenalcare.co.za)
- **T Mailola Speech Therapy & Audiology**: hearing, speech and swallowing
